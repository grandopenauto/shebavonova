# Shebavonova

Shebavonova is an HDP superintelligence development program focused on governed orchestration, commercial reasoning, autonomous operations, evidence, and compounding system intelligence.

This repository contains the public static project site for the Shebavonova development program.

## Site structure

- `index.html` — page content and semantic structure
- `styles.css` — responsive visual system, animation, and layout
- `app.js` — reveal effects, counters, navigation state, and pointer lighting
- `favicon.svg` — project favicon
- `.nojekyll` — serve the static site directly with GitHub Pages

## GitHub Pages

Publish from the repository's `main` branch and root (`/`). No build step or framework is required.

## Development direction

The site documents the program as a system-of-systems effort: orchestration, commercial intelligence, specialized operating agents, shared execution infrastructure, evidence, customer proof, governance, and adaptive planning.
